# 可信课程资料研究助手

一个面向大学生的课程资料问答项目。它基于用户提供的课程资料回答问题，尽可能展示答案依据，并研究错误信息或恶意指令如何影响检索增强 Agent。

## 项目愿景

帮助学生更快理解课程材料，同时让答案可核查：回答能指出资料出处；资料不足或互相矛盾时，明确说明不确定之处；检索到的内容被视为资料，而不是控制 Agent 的指令。

## 与前一个项目的联系

前一个项目实现了 Baseline、Tool、Planning、Reflection 等问答流程，并在固定检索材料上初步比较检索投毒与提示级防护。本项目把同一研究问题放进一个具体、可交互的课程资料场景：

> 当课程资料中包含错误信息、相互矛盾的说法或恶意指令时，检索增强助手会如何回答？哪些设计能让回答更可靠？

前项目的 4 道投毒题和试运行结果仅作为研究起点，不直接当作本项目的评测结论。

## 首版目标

首版聚焦一门课程和 PDF 资料，完成以下流程：

1. 导入课程 PDF 并建立可检索的资料索引。
2. 用户用自然语言提问，助手基于资料回答。
3. 展示答案所依据的文件和页码或文本片段。
4. 当没有足够依据或资料内容冲突时，明确提示用户。
5. 用固定测试问题比较基础问答与可靠性改进方案。

## 首版暂不做

- 多课程、多用户的完整平台
- 自主执行外部操作的复杂多 Agent 系统
- 从头训练或全量微调大模型
- 未经评测就宣称能够防止所有提示注入或幻觉

## 评估重点

- 答案正确性与完整性
- 引用是否能支持对应回答
- 资料不足时是否恰当拒答或表达不确定
- 投毒内容是否改变答案或让 Agent 服从资料中的指令
- 调用次数、响应时间等成本

每项结论都应注明数据集规模、模型、提示版本和实验条件。小样本结果只描述为观察，不外推成普遍保证。

## 技术路线

先以 Python 建立最小可运行版本，再按阶段加入 PDF 解析、检索、答案引用、评测集和可靠性对照实验。具体依赖和模型服务在实现前确定，避免首版被框架选择牵着走。
